# Community Cannabis

Static website draft and research package for Community Cannabis in Pattaya.

## Project Structure

- `website/` - production-facing static one-page site.
- `site-research/` - collected research notes, source references, and supporting assets used to build the page.

Run locally:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory website
```

Then open `http://127.0.0.1:4173/`.
