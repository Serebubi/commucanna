# Community Cannabis site research pack

Collected: 2026-05-27, Europe/Moscow workspace time. The store itself is in Thailand, so Google Maps current-day status may reflect Thailand local date/time.

This folder contains the working material for a future one-page website for **Community Cannabis ชุมชนกัญชา** in Pattaya / Chon Buri.

## Files

- `site-report.md` - full research report for planning the site.
- `business-data.json` - structured business facts for development, schema, and content blocks.
- `site-content-draft.md` - draft website copy and section structure.
- `implementation-brief.md` - practical build brief, page requirements, schema draft, and owner questions.
- `reviews-insights.md` - review themes and reputation summary without republishing full third-party reviews.
- `facebook-source-report.md` - public Facebook About page data, social links, service details, and saved browser artifacts.
- `facebook-wall-report.md` - public Facebook wall/photo-post extraction, product signals, operations notes, and usage recommendations.
- `facebook-wall-data.json` - structured extraction from public wall and photo-post captions.
- `sources.md` - source links, conflicts, and verification notes.
- `stitch-summary.md` - Stitch MCP project/screen IDs and saved generated output.
- `assets/ASSET_INVENTORY.md` - all saved image/screenshot files with notes and usage status.
- `assets/source-images/` - downloaded public listing images from Weed.th and Cannawayz/Mapbox references.
- `assets/screenshots/` - screenshots of source pages and Google photo panel for design/reference.
- `stitch-output/` - generated Stitch screen HTML and screenshot from the configured Stitch MCP endpoint.
- `stitch-*-response.json` - raw Stitch MCP responses for project/screen traceability.

## Important use notes

The downloaded and screenshotted photos are research/reference assets. Before using any image publicly on the final website, get permission from the owner or replace it with newly shot original photos.

Cannabis rules in Thailand are legally sensitive and have changed over time. The final website should include age gating, avoid medical claims, avoid targeting minors, and have the current legal/compliance text reviewed before launch.
