# Community Cannabis website draft

Static one-page website draft for Community Cannabis ชุมชนกัญชา.

Open locally from the project root:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory website
```

Then visit:

```text
http://127.0.0.1:4173
```

## Files

- `index.html` - page markup, SEO metadata, JSON-LD.
- `styles.css` - responsive visual design.
- `script.js` - 21+ age gate, sticky header behavior, photo-menu filtering, flag language switching, parallax leaves, and image lightbox.
- `assets/images/` - local image assets copied from the research pack, generated transparent leaf curtains, SVG language flags, the Facebook profile/logo image, and selected public Facebook wall images.
